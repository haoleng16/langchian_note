# 概述

通过清除旧工具调用输出，在达到令牌限制时管理对话上下文，同时保留近期结果。这有助于在长时间对话中保持上下文窗口的可控性，尤其是涉及大量工具调用时。上下文编辑适用于以下情况：

- 长时间对话中，许多超出令牌限制的工具调用
- 通过移除不再相关的旧工具输出来降低代币成本
- 只维护最新的 N 工具会得到上下文

## 作用

它的核心作用是：当对话历史或 Tool（工具）调用的输出太长，超过了 LLM 的 Token 限制时，自动**裁剪、清理或压缩**旧的、不重要的信息（通常是旧的工具调用结果），以防止 Token 溢出并节省成本

## 参数

| 参数名               | 类型        | 说明                                                                                                                       |
| ----------------- | --------- | ------------------------------------------------------------------------------------------------------------------------ |
| trigger_tokens    | int       | **触发阈值**。当上下文的总 Token 数超过这个数值时，清理逻辑才会启动                                                                                  |
| keep              | dict或int  | **保留策略**。指定要“保留”多少条最近的记录，其余旧的会被清理                                                                                        |
| exclude_tools     | List[str] | **排除名单**。如果你有一些关键工具（比如“设定用户偏好”的工具）的输出**永远不想被清理**，就把工具的名字（字符串）放在这里。                                                       |
| clear_tool_inputs | bool      | **是否清除输入参数**。 <br> True: 清除工具的返回值的同时，也把当初调用工具的**参数**（Inputs）也删了。<br> False (默认): 只清除工具的**返回值**（Outputs），保留调用记录证明“我调用过它”。 |
| placeholder       | str       | **占位符**。被删除的内容会被替换成这段文字                                                                                                  |
| cleart_at_least   | int       | 编辑执行时,最低可收回token数,设置为0,则可以清除所需的所有内容                                                                                      |
## 使用示例
```
custom_context_middleware = ContextEditingMiddleware(
                edits=[
                    ClearToolUsesEdit(
                        trigger=300,                # 当 token 数超过 300 时触发清理（约 3-4 次工具调用后）
                        keep=1,                     # 只保留最近的 1 个工具结果
                        clear_at_least=0,           # 清理所有超出keep数量的内容
                        clear_tool_inputs=False,    # 不清理工具输入参数
                        exclude_tools=["generate_report"],  # 不清理 generate_report 的结果
                        placeholder="[已清理以节省空间]",
                    )
                ],
                token_count_method="approximate",  # 使用近似计数（更快）
            )
```
